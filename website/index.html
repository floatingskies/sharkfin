why

A daily driver, not a project.

These images start from the strongest bases on Linux and add only the little things I miss, so the machine behaves like mine from the first boot.

  • Atomic & signed — immutable images with clean rollbacks, verified with cosign.
  • One GNOME, everywhere — the same curated desktop, on every channel.
  • Wallpapers that wander — System76, Framework, Ubuntu, and KDE/Plasma collections, all in the picker — plus the funny shark by default.
  • Little comforts — Chrome as the browser, Intel One Mono, Ctrl+Alt+T terminal.
  • Flatpaks curated — a chosen set of sandboxed apps installs automatically at first boot, with nothing duplicated.
  • A real installer — boot the ISO to try it, or install it to disk; Secure Boot works.

make it yours

Boot or install in minutes.

Try it live

Write the ISO to a USB stick with balenaEtcher, Rufus, or on Linux/macOS:

sudo dd if=Sharkfin-...live-amd64.iso \
  of=/dev/sdX bs=4M status=progress

Find the right device with lsblk, then boot from the stick.

Install it for good

Launch Install to Disk from the live desktop (Anaconda). Secure Boot is supported — enroll the Universal Blue key or keep your own. Already on an Atomic system?

sudo bootc switch \
  ghcr.io/floatingskies/sharkfin-bluefin:latest

Then systemctl reboot. Roll back anytime from the boot menu.
